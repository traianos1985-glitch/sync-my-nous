# NOUS AI OS — Απομακρυσμένη Πρόσβαση από Κινητό

Δύο τρόποι να χρησιμοποιείς τον NOUS από το κινητό σου
ενώ ο υπολογιστής είναι στο σπίτι:

---

## Μέθοδος 1: ngrok (Πιο εύκολη — Δωρεάν)

Δίνει ένα **δημόσιο URL** (π.χ. `https://abc123.ngrok-free.app`)
που λειτουργεί **από οπουδήποτε** — σπίτι, καφετέρια, εξωτερικό.

**Βήματα:**
1. Φτιάξε δωρεάν λογαριασμό: https://ngrok.com
2. Κατέβασε το ngrok: https://ngrok.com/download
3. Σύνδεσε τον λογαριασμό σου:
   ```
   ngrok config add-authtoken YOUR_TOKEN_FROM_NGROK_DASHBOARD
   ```
4. Τρέξε το NOUS τοπικά
5. Τρέξε το tunnel:
   - **Windows:** `deploy\remote_access\setup_ngrok_windows.bat`
   - **Mac/Linux:** `bash deploy/remote_access/setup_ngrok_mac_linux.sh`
6. Αντέγραψε το URL που εμφανίζεται → άνοιξέ το στο κινητό

**Σημείωση:** Με δωρεάν λογαριασμό το URL αλλάζει κάθε φορά που επανεκκινείς το ngrok.
Για σταθερό URL: πλάνο ngrok ~$10/μήνα ή χρησιμοποίησε Tailscale.

---

## Μέθοδος 2: Tailscale (Πιο ασφαλής — Δωρεάν έως 100 συσκευές)

Δημιουργεί **ιδιωτικό VPN** μεταξύ των συσκευών σου.
Κανείς άλλος δεν μπορεί να δει τον NOUS — μόνο εσύ.

**Βήματα:**
1. Φτιάξε δωρεάν λογαριασμό: https://tailscale.com
2. Στον υπολογιστή:
   - **Windows/Mac:** Κατέβασε από https://tailscale.com/download
   - **Linux:** `bash deploy/remote_access/setup_tailscale.sh`
3. Στο κινητό: Εγκατάστησε το **Tailscale app** (iOS/Android)
4. Συνδέσου με τον ίδιο λογαριασμό και στα δύο
5. Βρες την Tailscale IP του PC (π.χ. `100.x.x.x`) στο Tailscale dashboard
6. Άνοιξε από κινητό: `http://100.x.x.x:5000`

**Πλεονέκτημα:** Σταθερή IP, πάντα λειτουργεί, χωρίς port forwarding.

---

## Σύγκριση

| | ngrok | Tailscale |
|---|---|---|
| Κόστος | Δωρεάν (URL αλλάζει) | Δωρεάν (σταθερό) |
| Εγκατάσταση | 5 λεπτά | 10 λεπτά |
| Πρόσβαση | Από παντού | Μόνο Tailscale συσκευές |
| Ασφάλεια | Καλή | Εξαιρετική |
| Συνιστάται για | Γρήγορο test | Μόνιμη χρήση |

---

## Σημαντικό

Ο υπολογιστής **πρέπει να είναι ανοιχτός** για να λειτουργεί η απομακρυσμένη πρόσβαση.
Για 24/7 πρόσβαση χωρίς να αφήνεις τον PC ανοιχτό → χρησιμοποίησε VPS (βλ. deploy/README.md).
